# InstantHorseJump

InstantHorseJump is a lightweight client-side Fabric mod that makes horses jump immediately at full charge when you press the jump key.

There is no need to hold the key to charge or release it to jump. Each horse keeps its original jump-strength attribute; the mod simply triggers every jump at 100% charge.

## ✨ Features

- Jump immediately with a single key press
- Always uses 100% charge
- No holding or key release required
- Preserves each horse's original jump strength
- Prevents repeated jumps while the key is held
- Supports compatible horse-family mounts
- Client-side only; server installation is not required
- Fabric API is not required

## ⚙️ Installation

1. Install Fabric Loader.
2. Place the InstantHorseJump JAR in your `mods` folder.
3. Launch the game and press the jump key while riding a horse.

## 🛠️ Building

Run the included Gradle Wrapper:

```bat
.\gradlew.bat build
```

The built JAR is generated in `build/libs/`.

# InstantHorseJump（日本語）

InstantHorseJumpは、ジャンプキーを押した瞬間に、馬を最大チャージでジャンプさせる軽量なクライアント側Fabric MODです。

ジャンプキーを長押ししてチャージしたり、キーを離してジャンプを発動したりする必要はありません。馬が本来持っているジャンプ力の個体差は維持され、チャージ量だけが毎回100%になります。

## ✨ 主な機能

- ジャンプキーを一度押すだけで即座にジャンプ
- 毎回100%のチャージでジャンプ
- キーの長押しや、離す操作が不要
- 馬ごとの本来のジャンプ力を維持
- キーを長押ししても連続発動しない
- 対応する馬系の乗り物で動作
- クライアント側のみで動作し、サーバー側への導入は不要
- Fabric API不要

## ⚙️ 導入方法

1. Fabric Loaderを導入します。
2. InstantHorseJumpのJARを`mods`フォルダに入れます。
3. ゲームを起動し、馬に乗ってジャンプキーを押します。

## 🛠️ ビルド

同梱のGradle Wrapperを実行します。

```bat
.\gradlew.bat build
```

完成したJARは`build/libs/`に生成されます。
